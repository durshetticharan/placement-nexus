# Placement Nexus

**Integrated Campus Recruitment, Career Development & Employability Intelligence Platform**

CMR Technical Campus · Department of Computer Science and Engineering · Batch 08

## Overview

Placement Nexus goes beyond a traditional placement portal. Alongside managing recruitment (drives, applications, interviews, selections), it continuously measures and improves student employability through skill-gap analysis, career-specific readiness scoring, assessments, and AI-assisted resume/career guidance — while giving verified alumni a structured way to share referrals, drive experiences, and mentorship.

## Roles

- **Student** — builds a profile, takes assessments, tracks skill gaps, checks readiness, applies to drives
- **Recruiter** — posts placement drives, gets explainable candidate ranking, manages interviews/selection
- **Placement Officer** — verifies recruiters/alumni/companies, manages drives, views institutional analytics
- **Alumni** — verified former students who offer referrals, share drive experiences, and provide mentorship

## Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js, Express, TypeScript, Prisma
- **Database:** PostgreSQL
- **AI Service:** Python, FastAPI
- **DevOps:** Docker, Docker Compose, GitHub Actions
